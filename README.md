## 🚀 How to Run Locally

### Option 1: Direct File Open (Zero Dependencies)
Simply double-click `index.html` or open it with your browser:
- On Windows: Right-click `index.html` -> Open with -> Google Chrome / Microsoft Edge.

### Option 2: Using Node / npx serve
In the `portfolio` directory, run:
```bash
npx serve . -l 3000
```
Then visit `http://localhost:3000` in your browser.

### Option 3: Using Python
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Free Instant Deployment Guides

### 1. GitHub Pages (Recommended)
1. Initialize git in this directory (or push to your GitHub account):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Methun Raj A portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
   git push -u origin main
   ```
2. Your portfolio will be live at `https://<your-username>.github.io`!

### 2. Netlify / Vercel
1. Drag and drop the `portfolio` folder directly into the Netlify Drop dashboard ([app.netlify.com/drop](https://app.netlify.com/drop)).
2. Your site will be online in under 10 seconds with a free HTTPS custom domain.
